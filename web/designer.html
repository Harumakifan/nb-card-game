费用价值 1.0　（能量×1 ＋ 祭品×1.5 ＋ 骨头×0.5，仅供设计参考）

词条

· 需要填写数值或效果。词条带数字时写作「词条_数值」，例：多重攻击_2、激奏_能量1、爆能强化_骨头6、亡者召还_能量5。
词条按种类过滤：法术只有 融合 / 爆能强化 / 激奏 / 结晶 / 连击 / 亡者召还；护符只有 潜行 / 灵气 / 位移 / 倒计时 / 入场曲 / 谢幕曲 / 回合开始时 / 回合结束时 / 瞬念召唤 / 融合 / 爆能强化 / 激奏 / 结晶 / 连击 / 启动 / 亡者召还；随从不受限。
「破坏 / 消失 / 变身」是术语。「抉择」不是独立词条：在【入场曲】或【启动】那一行点「改为抉择」，之后可以把亡者召还设为「接在抉择」。

术语表（不可勾选）
破坏将随从送入墓地。触发【谢幕曲】，产生骨头。
消失将随从移出对局。不进入墓地、不触发【谢幕曲】、不产生骨头。
变身将该随从变为指定的另一随从，原能力与状态失效。
祭品打出或召唤时，必须破坏自己的随从作为代价。祭品不是费用，不能被任何效果「比较大小」。
召唤将随从直接放置到战场上（非从手牌打出）。
造成伤害对目标造成伤害；与「失去生命值」区分。
回复恢复生命值，不超过上限。
抽取从牌库取卡牌加入手牌。
毁灭词条：该随从对随从造成伤害时，破坏该随从。
